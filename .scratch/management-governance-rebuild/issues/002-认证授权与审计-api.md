# 002 认证授权与审计 API

- **状态：** blocked
- **阻塞：** 001
- **阻塞后续：** 003、004

## 目标

将成员会话、全局与项目角色、归档状态和审计写入统一在 FastAPI HTTP 边界强制执行，提供管理中心所需的资源化 API。

## 范围

- 成员列表、创建、姓名编辑、临时密码重置、启用/停用和系统角色管理。
- 当前身份和强制修改密码流程；停用或重置密码即时废止旧会话。
- 项目列表、创建、资料编辑、负责人转移、归档和恢复。
- 成员到项目的直接授权列表、授予/更新和撤销。
- 只读审计日志的筛选与服务端分页。
- 在已有文档、草稿、发布和 MCP 路由上统一执行新角色与项目状态约束。

## 验收标准

- 所有管理接口仅系统管理员可使用；项目管理员只可治理其活动项目的授权、负责人和资料。
- `viewer`、`editor`、`project_admin` 的文档行为严格符合重构规格。
- 已停用成员和已被重置密码成员的既有 JWT 立刻失效。
- 每次规定的管理变更恰好产生一条脱敏审计记录。
- 归档项目拒绝写入和授权修改，并维持已有成员的只读访问。
- HTTP 边界测试覆盖正常路径、越权、冲突和安全不变量。

## 非目标

- 前端管理界面。
- 审计清理、外部身份或用户组。
