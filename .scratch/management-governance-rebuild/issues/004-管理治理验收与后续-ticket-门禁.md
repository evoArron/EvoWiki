# 004 管理治理验收与后续 Ticket 门禁

- **状态：** blocked
- **阻塞：** 001、002、003
- **阻塞后续：** 其余 MVP Tickets

## 目标

通过管理治理的端到端验收，确认成员、项目、直接授权、会话失效和审计行为可靠后，再恢复未完成 MVP Ticket 的实施。

## 范围

- 运行后端 HTTP 边界测试和前端管理中心行为测试。
- 验证系统管理员、项目管理员、编辑者和查看者的关键工作流。
- 验证停用、密码重置、负责人转移、归档、授权撤销和审计脱敏。
- 运行 GitNexus 影响分析与变更检测，确认管理重构没有扩大到 Git 发布、RAG 或 MCP 的非预期范围。
- 更新重构规格的已实现状态，并明确解除后续 MVP Tickets 的阻塞。

## 验收标准

- 所有管理治理测试通过，且没有已知的权限绕过、会话残留或审计泄密。
- 现有文档路径沙箱、Markdown 草稿隔离和服务唯一 Git 推送者约束仍成立。
- GitNexus 检测只报告规格预期的符号和流程影响。
- 后续 MVP Tickets 的阻塞关系被明确解除或保留并写明原因。

## 非目标

- 实现被管理治理重构阻塞的其余 MVP 功能。
- V2 的审计清理、备份恢复、SSO 或密码策略。
