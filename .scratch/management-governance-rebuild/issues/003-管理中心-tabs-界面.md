# 003 管理中心 Tabs 界面

- **状态：** blocked
- **阻塞：** 002
- **阻塞后续：** 004

## 目标

将右上角设置入口改造成系统管理员可用的宽管理抽屉，以成员、项目和审计日志 Tabs 提供完整治理操作，并使用二级抽屉处理新增和编辑。

## 范围

- 系统管理员可见的设置入口和宽管理抽屉。
- 成员 Tab：紧凑表格、搜索、状态筛选、文字头像、创建/编辑/重置密码/启停/系统角色操作。
- 项目 Tab：紧凑表格、搜索、状态筛选、创建/编辑/负责人转移/归档/恢复，以及项目内直接授权维护。
- 审计日志 Tab：只读表格、筛选和分页。
- 二级抽屉提交管理操作，显示明确成功、冲突和权限错误。
- 非系统管理员不显示或无法打开管理中心；归档项目展示只读状态。

## 验收标准

- 管理中心不再包含三张一次性手工表单。
- 成员、项目和审计记录均通过后端 API 加载；前端不自行推断权限或状态。
- 表格与抽屉在桌面及窄视口下没有文本溢出或不可达操作。
- 所有二级抽屉保存后刷新受影响的数据，失败时保留用户输入并显示可理解的错误。
- 前端行为测试覆盖 Tabs、权限可见性、筛选、二级抽屉和归档只读状态。

## 非目标

- 独立路由的后台站点、用户组、邮件邀请或图片头像。
